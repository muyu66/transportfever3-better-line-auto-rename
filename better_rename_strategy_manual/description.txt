Better Rename Strategy (Manual)

Note
Better Rename Strategy (Auto-apply) is the auto-naming version of the same strategy—note that you can only choose one of the two.

Feature Overview
A very simple mod that only adds a new line naming scheme: Cargo - First Stop - Last Stop.

How It Works
It combines schemes built into the base game. This scheme does not add new components; it directly reuses the three existing rename_scheme_components in the base game.
